## 一、控制方法

### 1.1 三种控制方式总览

云台电机有且仅有三种运动方式，分别对应三个目标命令：

| 控制方式 | 控制模式（0x00） | 目标命令 | 目标单位 |
|----------|:----------------:|:--------:|----------|
| 速度控制 | mode 0 | `0x01` 转速 | RPM |
| 多圈位置控制 | mode 1（T）/ 3（直通） | `0x02` 位置 | 度（可跨圈） |
| 单圈绝对位置控制 | mode 2（T）/ 4（直通） | `0x03` 角度 | 度（0~359.9） |

**共同套路**：无论哪种方式，完整驱动序列都是四步：

```
加速度(0x07) → 控制模式(0x00) → 目标值(0x01/0x02/0x03) → 使能(0x06)
```

电机使能后（指示灯闪烁），才会按当前模式和目标值运动。

### 1.2 速度控制（含顺/逆时针）

```
加速度(0x07) → 模式(0x00, mode=0) → 转速(0x01) → 使能(0x06)
```

- 转速是 16 位有符号数，**正负号决定方向**：`spin 50` 正向、`spin -50` 反向。
- `cw`（顺时针）/ `ccw`（逆时针）只是对正负号的语义封装。
- 实际「顺/逆」取决于电机接线，方向反了对调 `cw`/`ccw` 即可。

```bash
python cli.py --port COM3 --address 1 spin 50     # 50 RPM
python cli.py --port COM3 --address 1 cw 50       # 顺时针 50 RPM
python cli.py --port COM3 --address 1 ccw 50      # 逆时针 50 RPM
python cli.py --port COM3 --address 1 stop        # 停转失能
```

### 1.3 多圈位置控制

```
加速度(0x07) → 模式(0x00, mode=1) → 位置(0x02) → 使能(0x06)
```

- 目标是**绝对位置**（相对零点），可跨多圈：`720.0°` = 两圈。
- 位置是 32 位有符号，单位 0.1°（按度 ×10 发送）。

```bash
python cli.py --port COM3 --address 1 position 720    # 转到 720°（两圈）
```

### 1.4 单圈绝对位置控制

```
加速度(0x07) → 模式(0x00, mode=2) → 角度(0x03) → 使能(0x06)
```

- 目标是单圈内的**绝对角度**，范围 0~359.9°。
- 角度是 16 位，单位 0.1°（按度 ×10 发送）。

```bash
python cli.py --port COM3 --address 1 angle 90        # 转到 90.0°
```

### 1.5 双电机分别控制

两块电机级联在同一条串口总线，靠帧里的**地址字节**区分：

| 电机 | 轴 | 地址 |
|------|----|:----:|
| X 轴 | Yaw（水平） | 1 |
| Y 轴 | Pitch（俯仰） | 2 |

```bash
python cli.py --port COM3 --address 1 spin 50     # 只动 X 轴
python cli.py --port COM3 --address 2 spin 30     # 只动 Y 轴
```

> 地址出厂默认都是 2，需用 `0x0D` 把 X 轴改成 1（详见 `实际操作总结.md` 第 5 节）。

## 二、代码实现原理

### 2.1 整体架构

```
blcd_controller.py
├── 常量层   CMD_*（命令码）、MODE_*（模式）、FRAME_HEAD/TAIL、ADDR_BROADCAST
├── 串口层   open / close / list_ports
├── 协议层   _checksum / _frame / _send / _read_frame
├── 命令层   每个命令码一个方法（set_speed / set_position / set_angle ...）
├── 序列层   高层便捷方法（spin / stop / move_position / move_angle）
└── 解析层   read_params / _parse_read_all
```

分层的好处：底层只关心「怎么把字节发出去」，上层只关心「业务语义」（转、停、到位）。

### 2.2 协议帧的构造

每个命令帧结构固定：

```
0x7A | 地址 | 命令码 | 数据(大端, 可选) | 校验 | 0x7B
```

核心在 `_frame()` 与 `_checksum()`：

```python
@staticmethod
def _checksum(data):
    """XOR 校验：对 data 的所有字节逐字节异或，返回低字节。"""
    c = 0
    for b in data:
        c ^= b
    return c & 0xFF

def _frame(self, cmd, payload=b"", addr=None):
    if addr is None:
        addr = self.address
    body = bytes((self.FRAME_HEAD, addr & 0xFF, cmd & 0xFF)) + bytes(payload)
    return body + bytes((self._checksum(body), self.FRAME_TAIL))
```

- `body` = `帧头 + 地址 + 命令码 + 数据`，校验是对 `body` 所有字节异或。
- 数据由调用方提前用 `struct.pack` 打好**大端序**（`>h` / `>i`）。

### 2.3 校验算法（BCC / XOR）

从 `0x7A` 帧头起、到校验字节之前的所有字节逐字节异或。例：使能 X 轴

```
7A ^ 01 ^ 06 = 7D   →   帧 = 7A 01 06 7D 7B
```

设备收到帧后按同样算法验算，校验对不上就丢弃该帧——所以只要校验对，命令就是可靠的。

### 2.4 串口收发

```python
def _send(self, frame):
    if self.ser is None or not self.ser.is_open:
        raise RuntimeError("串口未打开，请先调用 open()")
    self.ser.reset_input_buffer()   # 丢弃残留数据，避免解析到陈旧帧
    self.ser.write(frame)
    self.ser.flush()
```

- 发送前 `reset_input_buffer()` 清掉上一次的残留字节，防止读到陈旧响应。
- 写完后 `flush()` 确保字节真正发出。

```python
def _read_frame(self, timeout=1.0, strict=True):
    ...
    # strict=True  校验通过才返回
    # strict=False 找到帧头帧尾即返回（本板响应 checksum 常对不上）
```

- 读取时从字节流里找 `0x7A ... 0x7B` 成对出现，再校验。
- 因为 CH9102 芯片读取时有**间歇性位错误**（帧头 `0x7A` 常变 `0x70`、校验和常错），
  `read_params()` 采取「先严格、后宽松、多次重试」策略：

```python
for strict in (True, False, False, False):
    self._send(self._frame(self.CMD_READ_ALL, addr=self.ADDR_BROADCAST))
    frame = self._read_frame(timeout=1.0, strict=strict)
    if frame is not None and len(frame) == 20 and ...:
        return self._parse_read_all(frame)
```

### 2.5 命令封装层

每个命令码对应一个方法，只做「把语义值转成字节、组帧、发送」三件事：

```python
def set_speed(self, speed, addr=None):
    """转速（0x01，16 位有符号）。"""
    self._send(self._frame(self.CMD_SPEED, struct.pack(">h", speed), addr))

def set_position(self, position, addr=None):
    """多圈绝对位置（0x02，32 位有符号，度 ×10）。"""
    self._send(self._frame(self.CMD_POSITION,
                           struct.pack(">i", int(round(position * 10))), addr))

def set_angle(self, angle, addr=None):
    """单圈绝对角度（0x03，16 位，度 ×10）。"""
    self._send(self._frame(self.CMD_ANGLE,
                           struct.pack(">h", int(round(angle * 10))), addr))

def set_accel(self, accel, addr=None):
    """加速度（0x07，16 位有符号，转/s²）。"""
    self._send(self._frame(self.CMD_ACCEL, struct.pack(">h", accel), addr))

def set_mode(self, mode, addr=None):
    """控制模式（0x00）。帧 7A addr 00 00 mode cs 7B。"""
    self._send(self._frame(self.CMD_MODE, bytes((0x00, mode & 0xFF)), addr))
```

### 2.6 高层序列封装

`spin` / `move_position` / `move_angle` 把四步序列串起来，中间加小延时让设备逐条处理：

```python
def spin(self, speed, addr=None, accel=100, delay=0.1):
    self.set_accel(accel, addr=addr);  time.sleep(delay)
    self.set_mode(0, addr=addr);       time.sleep(delay)
    self.set_speed(speed, addr=addr);  time.sleep(delay)
    self.enable(addr=addr)

def move_position(self, position, addr=None, accel=100, mode=None, delay=0.1):
    if mode is None:
        mode = self.MODE_MULTI_TURN_T
    self.set_accel(accel, addr=addr);  time.sleep(delay)
    self.set_mode(mode, addr=addr);    time.sleep(delay)
    self.set_position(position, addr=addr); time.sleep(delay)
    self.enable(addr=addr)
```

`spin_cw` / `spin_ccw` 只是对 `spin` 的正负号封装：

```python
def spin_cw(self, speed, addr=None, accel=100, delay=0.1):
    self.spin(abs(speed), addr=addr, accel=accel, delay=delay)

def spin_ccw(self, speed, addr=None, accel=100, delay=0.1):
    self.spin(-abs(speed), addr=addr, accel=accel, delay=delay)
```

### 2.7 响应解析

`read_params()` 发 `0x0C` 广播读，设备回 20 字节；`_parse_read_all()` 按字段切分：

```python
def _parse_read_all(self, frame):
    data = frame[2:18]                        # 跳过 0x7A 与地址回显字节
    turns       = struct.unpack(">i", data[0:4])[0]   # 转过角度 ÷10=圈
    angle       = struct.unpack(">h", data[4:6])[0]   # 机械角度 ÷10=°
    bus_voltage = struct.unpack(">h", data[6:8])[0]   # 母线电压 ÷10=V
    speed       = struct.unpack(">h", data[8:10])[0]  # 电机速度 ÷100
    current     = struct.unpack(">h", data[10:12])[0] # 电流 mA
    kp_s, ki_s, kp_p, ki_p = data[12], data[13], data[14], data[15]
    return {..., "address": frame[1], ...}
```

`frame[1]` 是设备回显的**自身地址**，读出来后可以直接确认「改地址」是否成功。

### 2.8 地址管理

```python
def set_address(self, new_addr, addr=None):
    """地址设置（0x0D，数据 1 字节 = 新地址）。"""
    self._send(self._frame(self.CMD_SET_ADDR, bytes((new_addr & 0xFF,)), addr))
```

- 帧结构：`7A [当前地址] 0D [新地址] cs 7B`，例 `7A 02 0D 01 74 7B` 把地址 2 改成 1。
- 改完立即生效（RAM），需再发 `save_params()`（0x08）到**新地址**才掉电保存。
- 级联时**必须先拔掉一台**再改，否则两台同时被改成同一地址。

### 2.9 数据编码规则（易错点）

| 规则 | 说明 |
|------|------|
| **大端序** | 多字节一律 `struct.pack(">...")`，高字节在前 |
| **×10** | 位置/角度按「度」传入，内部 ×10（官方手册「放大十倍」） |
| **转速不 ×10** | `0x01` 转速直接是 RPM，如 100 = 100 RPM |
| **命令码别搞反** | `0x01`=转速、`0x07`=加速度；`0x04` 已废弃 |
| **地址字节** | 每个帧都带目标地址，是区分两台电机的唯一依据 |

## 三、附：命令码与模式速查

### 命令码

| 码 | 功能 | 码 | 功能 |
|:--:|------|:--:|------|
| 0x00 | 控制模式 | 0x0A | 单圈零点 |
| 0x01 | 转速 | 0x0B | 恢复出厂（地址→2） |
| 0x02 | 多圈位置 | 0x0C | 读参数（广播） |
| 0x03 | 单圈角度 | 0x0D | 地址设置 |
| 0x05 | 失能 | 0x0E | 数据反馈请求 |
| 0x06 | 使能 | 0x0F~0x12 | PID KP/KI |
| 0x07 | 加速度 | | |
| 0x08 | 保存参数 | | |
| 0x09 | 转过角度清零 | | |

### 控制模式

| mode | 模式 |
|:----:|------|
| 0 | 速度控制 |
| 1 | 多圈位置控制-T |
| 2 | 单圈绝对位置控制-T |
| 3 | 多圈位置控制-直通 |
| 4 | 单圈绝对位置控制-直通 |
