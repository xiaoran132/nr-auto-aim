## 1. 硬件与串口

| 项 | 值 |
|----|----|
| 电机 | F32C 二自由度无刷云台（X 轴=Yaw，Y 轴=Pitch） |
| 接线 | 两电机**级联**在同一条 TTL 串口总线（X 轴接口一是总入口） |
| USB 转串口芯片 | CH9102（VID:PID = 1A86:55D4） |
| 串口号 | `COM3` |
| 波特率 | **115200**（8 数据位 / 无校验 / 1 停止位 / 无流控） |

> ⚠️ 波特率是 **115200**，不是某些资料里写的 921600。

## 2. 协议帧格式

### 2.1 主机 → 设备（命令帧）

```
0x7A | 地址 | 命令码 | 数据(大端序, 可选) | XOR校验 | 0x7B
```

- 帧头 `0x7A`，帧尾 `0x7B`
- **地址**：目标设备地址（出厂默认 = 2；云台约定 X=1、Y=2）
- **校验**：从 `0x7A` 帧头起、到校验字节之前的所有字节逐字节异或，取低字节

按数据长度分四种帧：

| 帧长 | 结构 | 适用命令 |
|------|------|----------|
| 5 字节 | `7A addr cmd cs 7B` | 无数据命令（使能/失能/保存/恢复出厂/置零等） |
| 6 字节 | `7A addr cmd value cs 7B` | 8 位数据（0x0D 地址设置） |
| 7 字节 | `7A addr cmd d_hi d_lo cs 7B` | 16 位数据，或 8 位 + 保留高字节 |
| 9 字节 | `7A addr cmd d3 d2 d1 d0 cs 7B` | 32 位数据（0x02 多圈位置） |

**校验示例**（可用来验证自己的实现）：

| 帧 | 计算过程 | 校验 |
|----|----------|:----:|
| `7A 01 06 __ 7B`（使能 X 轴） | 7A^01^06 | `7D` |
| `7A 02 05 __ 7B`（失能） | 7A^02^05 | `7D` |
| `7A 02 08 __ 7B`（保存） | 7A^02^08 | `70` |
| `7A 02 0B __ 7B`（恢复出厂） | 7A^02^0B | `73` |
| `7A 02 0D 01 __ 7B`（地址 2→1） | 7A^02^0D^01 | `74` |
| `7A 01 08 __ 7B`（保存到地址 1） | 7A^01^08 | `73` |

### 2.2 设备 → 主机（响应帧，20 字节）

`read all`（命令 0x0C，地址 0xFF 广播）触发设备回传：

```
0x7A | 地址回显 | 转过角度(4B,÷10=圈) | 机械角度(2B,÷10=°) | 母线电压(2B,÷10=V)
     | 电机速度(2B,÷100) | 电流(2B,mA) | 速度PID KP(1B) | 速度PID KI(1B)
     | 位置PID KP(1B) | 位置PID KI(1B) | cs | 0x7B
```

| 偏移 | 字段 | 类型 | 换算 |
|------|------|------|------|
| 0 | 0x7A | 帧头 | — |
| 1 | 地址回显 | 8bit | 设备当前地址 |
| 2..5 | 转过角度 | 32bit BE | ÷10 = 圈 |
| 6..7 | 机械角度 | 16bit BE | ÷10 = 度 |
| 8..9 | 母线电压 | 16bit BE | ÷10 = 伏 |
| 10..11 | 电机速度 | 16bit BE | ÷100 |
| 12..13 | 电流 | 16bit BE | mA |
| 14..17 | 速度/位置 PID KP/KI | 4×8bit | 原值 |
| 18 | checksum | — | — |
| 19 | 0x7B | 帧尾 | — |

## 3. 命令码完整表

| 命令码 | 功能 | 数据 | 帧长 | 备注 |
|:------:|------|------|:----:|------|
| `0x00` | 控制模式选择 | 8bit mode | 7 | 帧 `7A addr 00 00 mode cs 7B` |
| `0x01` | **速度控制** | 16bit 有符号 | 7 | 单位 RPM，如 50 = 50 RPM |
| `0x02` | **多圈绝对角度** | 32bit 有符号 | 9 | 单位 0.1°，×10 发送 |
| `0x03` | **单圈绝对角度** | 16bit | 7 | 0~359.9°，×10 发送 |
| `0x04` | （废弃） | — | — | 官方手册未列出，勿用 |
| `0x05` | **电机失能** | 无 | 5 | |
| `0x06` | **电机使能** | 无 | 5 | 成功后电机指示灯闪烁 |
| `0x07` | **加速度控制** | 16bit 有符号 | 7 | 单位 转/s² |
| `0x08` | **保存设备参数** | 无 | 5 | 掉电保存 |
| `0x09` | 上电后转过角度清零 | 无 | 5 | 清多圈累计角度 |
| `0x0A` | 单圈绝对角度设零点 | 无 | 5 | 当前机械角度设为 0 |
| `0x0B` | **恢复出厂设置** | 无 | 5 | ⚠️ 地址重置回默认 2 |
| `0x0C` | 读取全部参数 | 无 | 5 | 地址用 0xFF 广播 |
| `0x0D` | **地址设置** | 8bit 新地址 | 6 | 帧 `7A addr 0D new cs 7B` |
| `0x0E` | 数据反馈请求 | 8bit 类型(00~04) | 6 | |
| `0x0F` | 速度环 KP | 8bit | 7 | |
| `0x10` | 速度环 KI | 8bit | 7 | |
| `0x11` | 位置环 KP | 8bit | 7 | |
| `0x12` | 位置环 KI | 8bit | 7 | |

> ⚠️ 关键：`0x01`=转速、`0x07`=加速度，两者曾弄反；`0x04` 已废弃；`0x0D`=改地址
> （不是电流）。这是本次调试早期电机「不转」「误改地址」的根源。

## 4. 控制模式

由命令 `0x00` 的数据位选择（帧 `7A addr 00 00 mode cs 7B`）：

| mode | 模式 | 说明 |
|:----:|------|------|
| 0 | 速度控制 | 配合 `0x01` 转速 |
| 1 | 多圈位置控制-T | 配合 `0x02`，梯形加减速 |
| 2 | 单圈绝对位置控制-T | 配合 `0x03`，梯形加减速 |
| 3 | 多圈位置控制-直通 | 配合 `0x02`，不走轨迹规划 |
| 4 | 单圈绝对位置控制-直通 | 配合 `0x03`，不走轨迹规划 |

- **T** = 梯形加减速（需要加速度参数 `0x07`），运动平滑；
- **直通** = 直接到位，不走轨迹规划。

## 5. 双电机地址管理

### 5.1 地址约定

| 电机 | 轴 | 地址 |
|------|----|:----:|
| X 轴 | Yaw（水平） | **1** |
| Y 轴 | Pitch（俯仰） | **2** |

- **出厂默认地址 = 2**（每台电机出厂都是 2，需手动把 X 轴改成 1）。

### 5.2 改地址（命令 0x0D）

**先拔线、单台操作**，否则两台会同时被改成同一地址。

```powershell
# 1. 断电 → 拔掉 Y 轴（Pitch）信号线，只留 X 轴 → 上电
# 2. 把 X 轴地址 2 → 1（发帧 7A 02 0D 01 74 7B）
python cli.py --port COM3 --address 2 setaddr 1
# 3. 掉电保存（发到新地址 1，帧 7A 01 08 73 7B）
python cli.py --port COM3 --address 1 save
# 4. 断电 → 插回 Y 轴 → 上电
```

> 改完地址立即生效（RAM），但必须再发「保存」(0x08) 才会掉电持久化；
> 保存帧要发到**新地址**。

## 6. 三种控制方式的驱动流程

每种方式的完整序列都是「**加速度 → 模式 → 目标值 → 使能**」四步。

### 6.1 速度控制

```
加速度(0x07) → 模式(0x00, mode=0) → 转速(0x01) → 使能(0x06)
```

```bash
python cli.py --port COM3 --address 1 spin 50     # X 轴 50 RPM（spin 已封装四步）
python cli.py --port COM3 --address 1 cw 50       # 顺时针 50 RPM
python cli.py --port COM3 --address 1 ccw 50      # 逆时针 50 RPM
```

> 方向由转速正负决定：`spin 50` 正向、`spin -50` 反向；`cw`/`ccw` 只是封装。
> 实际「顺/逆」与电机接线方向有关，若观察到方向反了，对调 `cw`/`ccw` 即可。

### 6.2 多圈位置控制

```
加速度(0x07) → 模式(0x00, mode=1) → 位置(0x02) → 使能(0x06)
```

```bash
python cli.py --port COM3 --address 1 position 720   # X 轴转到 720°（两圈）
```

### 6.3 单圈绝对位置控制

```
加速度(0x07) → 模式(0x00, mode=2) → 角度(0x03) → 使能(0x06)
```

```bash
python cli.py --port COM3 --address 1 angle 90       # X 轴转到 90.0°
```

> 位置/角度都按「度」输入，脚本内部自动 ×10（官方手册「放大十倍」）。


| 命令 | 说明 |
|------|------|

| `python cli.py --port COM3 read` | 读取全部参数（广播） |
| `python cli.py --port COM3 --address 1 spin 50` | X 轴速度控制 50 RPM |
| `python cli.py --port COM3 --address 1 cw 50` | X 轴顺时针旋转 50 RPM |
| `python cli.py --port COM3 --address 1 ccw 50` | X 轴逆时针旋转 50 RPM |
| `python cli.py --port COM3 --address 1 stop` | 停转并失能 |
| `python cli.py --port COM3 --address 1 position 720` | X 轴多圈位置到 720° |
| `python cli.py --port COM3 --address 1 angle 90` | X 轴单圈角度到 90° |
| `python cli.py --port COM3 --address 1 speed 500` | 设置转速（不自动使能） |
| `python cli.py --port COM3 --address 1 accel 100` | 设置加速度 |
| `python cli.py --port COM3 --address 1 mode 1` | 切换控制模式 |
| `python cli.py --port COM3 --address 1 enable` / `disable` | 使能 / 失能 |
| `python cli.py --port COM3 --address 1 zero` | 当前机械角度置零 |
| `python cli.py --port COM3 --address 1 save` | 保存参数 |
| `python cli.py --port COM3 --address 1 setaddr 1` | 改地址（见 5.2） |

```bash
python cli.py --port COM3 --address 1 spin 50     # X 轴转
python cli.py --port COM3 --address 2 spin 30     # Y 轴转
```

## 8. Python API（blcd_controller.py）

```python
from blcd_controller import BLDCController

c = BLDCController()
c.open('COM3', 115200)

# —— 速度控制 ——
c.spin(50, addr=1)          # X 轴 50 RPM（accel+模式+转速+使能）
c.spin(-50, addr=1)         # 反向 50 RPM（负号反转方向）
c.spin_cw(50, addr=1)       # 顺时针 50 RPM
c.spin_ccw(50, addr=1)      # 逆时针 50 RPM
c.stop(addr=1)              # 停转失能

# —— 多圈位置控制 ——
c.move_position(720.0, addr=1)   # 到 720°（默认 mode=1 多圈-T）

# —— 单圈绝对位置控制 ——
c.move_angle(90.0, addr=1)       # 到 90°（默认 mode=2 单圈-T）

# —— 直通模式 ——
c.move_position(720.0, addr=1, mode=c.MODE_MULTI_TURN_DIRECT)

# —— 底层命令（单条发送）——
c.set_mode(0, addr=1)       # 0=速度 1=多圈T 2=单圈T 3=多圈直通 4=单圈直通
c.set_speed(50, addr=1)     # 转速（0x01）
c.set_position(720.0, addr=1)  # 多圈位置（0x02，度×10）
c.set_angle(90.0, addr=1)   # 单圈角度（0x03，度×10）
c.set_accel(100, addr=1)    # 加速度（0x07）
c.enable(addr=1)            # 使能（0x06）
c.disable(addr=1)           # 失能（0x05）
c.set_address(1, addr=2)    # 改地址（0x0D）
c.save_params(addr=1)       # 保存（0x08）
c.read_params()             # 读参数（0x0C 广播），返回 dict（含 address）

c.close()
```

## 9. 坑与注意事项

1. **命令码别搞反**：`0x01`=转速、`0x07`=加速度。早期用 `0x04` 当转速命令导致电机
   不转（0x04 是废弃命令）。
2. **恢复出厂会重置地址**：`0x0B` 会把地址重置回默认 2。所以「两台都在地址 2」的
   bug 就是误发恢复出厂造成的。
3. **改地址必须先拔线**：级联状态下 0x0D 会同时命中两台，把两台改成同一地址。
4. **CH9102 串口读取有间歇位错误**：读回数据的帧头 `0x7A` 常被打成 `0x70`、校验和
   常对不上、偶发多出/少掉字节。但**发送命令可靠**——设备按校验和验证收到的帧。
   「读不回干净数据」≠「命令没送达」。
5. **广播读会碰撞**：两台在线时 `read`（0xFF 广播）会让两台同时应答、互相碰撞，读回
   乱码属正常。
6. **断电不丢地址/参数的前提是保存过**：改地址、改加速度等参数后需 `save`（0x08）
   才会掉电保存。
7. **严禁热插拔、严禁级联状态下烧录固件**：先断电再插拔线；烧录前必须断开级联单独烧。

## 10. 故障排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 灯闪但不转 | 转速命令用错（0x04 而非 0x01） | 用 `spin` 或确认命令码 |
| `--address 1` 无反应 | 该地址没设备（两台都在 2） | 用 `--address 2`，或改地址（见 5.2） |
| `--address 2` 两台一起动 | 两台都在地址 2 | 改地址分离（见 5.2） |
| 断电后参数丢失 | 没发 `save`（0x08） | 改完参数后 `save` |
| 读取乱码 / 校验失败 | CH9102 位错误 | 忽略，命令发送仍可靠 |
| 地址莫名其妙变 2 | 误发恢复出厂（0x0B） | 避免 `reset`，重新改地址 |
