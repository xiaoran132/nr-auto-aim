| 项目 | 内容 |
|------|------|

| 性质 | MiniBalance 无刷直流电机（BLDC）驱动器的 **PC 上位机配置软件** |
| 官方来源 | `https://minibalance.taobao.com/`（内嵌于程序资源中） |
| 主要功能 | 通过串口（UART）对电机驱动板进行参数配置与实时控制 |

### 1.2 技术栈

| 项目 | 值 |
|------|-----|
| UI 框架 | Qt 5（Core / Gui / Widgets / SerialPort / Svg） |

| 主窗口类 | `Widget`（继承 `QWidget`） |
| 符号状态 | 已 strip（外部 PDB），但导入表与 Qt 元对象数据完整保留 |

### 1.3 逆向方法

程序的符号虽被剥离，但以下两类信息完整保留，成为逆向突破口：

1. **导入表（IAT）**：保留了全部 Qt C++ 函数的 mangled 符号（如 `_ZN9QIODevice5writeEPKcx` = `QIODevice::write(const char*, qint64)`）。
2. **Qt 元对象数据**：由 `moc` 生成的 `staticMetaObject` 保留了类名、20 个槽函数名（`on_pushButton_clicked` 等）、信号槽签名和跳转表。

基于此，完成了：类结构重建 → 槽函数定位 → 逐函数反汇编 → 串口协议完整还原。

## 4. 串口通信协议（核心成果）

### 4.1 帧格式

```
┌──────┬────────┬────────┬──────────────┬──────────┬──────┐
│ 0x7A │  地址  │ 命令码  │  数据(大端序)  │ XOR校验  │ 0x7B │
│ 帧头  │ 1/2/FF │        │              │          │ 帧尾  │
└──────┴────────┴────────┴──────────────┴──────────┴──────┘
```

- **帧头** `0x7A`、**帧尾** `0x7B` 固定。
- **第 2 字节 = 设备地址**（`frame[1]`）：目标设备地址，读自界面上的「地址」输入框。双电机云台场景中 `1`=下电机、`2`=上电机；读取参数命令用 `0xFF` 广播。
- **第 3 字节 = 命令码**（`frame[2]`）。
- **数据一律大端序（网络字节序）**，长度随命令而异（0 / 8 / 16 / 32 位）。

### 4.2 校验算法

对从 **`0x7A` 帧头起、到校验字节之前**的所有字节做**逐字节异或（XOR）**，取低字节。

```
checksum = data[0] ^ data[1] ^ ... ^ data[n-1]
```

例：读取参数帧 `7A FF 0C 89 7B`，校验 = `0x7A ^ 0xFF ^ 0x0C` = `0x89`。

### 4.3 命令总表

| 命令码 | 功能 | 帧内容 | 数据类型 |
|:------:|------|--------|---------|
| `0x00` | 控制模式选择 | `7A [addr] 00 00 [mode] cs 7B` | 8 位（模式索引） |
| `0x01` | 加速度设置 | `7A [addr] 01 [h][l] cs 7B` | 16 位有符号 |
| `0x02` | 位置设置（多圈） | `7A [addr] 02 [b3][b2][b1][b0] cs 7B` | 32 位有符号（圈数含在 32 位内） |
| `0x03` | 角度设置（单圈） | `7A [addr] 03 [h][l] cs 7B` | 16 位 |
| `0x04` | 速度设置 | `7A [addr] 04 [h][l] cs 7B` | 16 位有符号 |
| `0x05` | **电机失能** | `7A [addr] 05 cs 7B` | 无 |
| `0x06` | **电机使能** | `7A [addr] 06 cs 7B` | 无 |
| `0x07` | ⚠️ 待定 | `7A [addr] 07 [h][l] cs 7B` | 16 位 |
| `0x08` | **保存设备参数** | `7A [addr] 08 cs 7B` | 无 |
| `0x0A` | **当前机械角度置零** | `7A [addr] 0A cs 7B` | 无 |
| `0x0B` | **恢复出厂设置** | `7A [addr] 0B cs 7B` | 无 |
| `0x0C` | **读取全部参数** | `7A FF 0C cs 7B`（`FF`=广播） | 无 |
| `0x0D` | 电流设置 | `7A [addr] 0D [v] cs 7B` | 8 位（6 字节帧） |
| `0x0F` | 速度环 PID KP | `7A [addr] 0F 00 [v] cs 7B` | 8 位 |
| `0x10` | 速度环 PID KI | `7A [addr] 10 00 [v] cs 7B` | 8 位 |
| `0x11` | 位置环 PID KP | `7A [addr] 11 00 [v] cs 7B` | 8 位 |
| `0x12` | 位置环 PID KI | `7A [addr] 12 00 [v] cs 7B` | 8 位 |

> `[addr]` = 目标设备地址（1=下电机，2=上电机）。⚠️ 标记的命令含义是**基于 UI 上下文推断**的，二进制中未直接确认，实际含义需配合固件验证。`0x0F~0x12` 对应四个 PID 参数（速度环 KP/KI、位置环 KP/KI）。

### 4.4 响应解析（读取全部参数 `0x0C`）

响应共 **20 字节**：

```
7A | 地址回显 | 转过角度(32位) | 机械角度(16位) | 母线电压(16位) | 速度(16位) | 电流(16位) | PID×4(各8位) | cs | 7B
```

| 字段 | 大小 | 单位换算 |
|------|------|---------|
| 转过角度 | 32 位（大端） | ÷10 |
| 机械角度 | 16 位（大端） | ÷10 |
| 母线电压 | 16 位（大端） | ÷10 |
| 电机速度 | 16 位（大端） | ÷100 |
| 电流 | 16 位（大端） | mA |
| PID×4 | 各 8 位 | 原始值 |

> 响应帧第 2 字节是**设备地址回显**（设备回报自己的地址），上位机会把它回写进「地址」输入框。

### 4.5 设备地址机制（双电机云台）

这是本协议区别于普通单电机上位机的关键设计，用于支持**一台主机通过一条串口总线控制多个电机**：

- 每条命令帧的第 2 字节是**目标设备地址**，读自界面上的「地址」输入框（`ui+0x1A0`，构造函数中挂了 `QIntValidator(0, 1500)`）。
- 两个电机组成云台时，约定 **地址 1 = 下方电机（俯仰/水平），地址 2 = 上方电机（横滚/垂直）**——同一串口总线上两机并联，靠地址字节区分命令归属。
- 协议中**未发现独立的“地址设置”命令**（`0x05` 实为“电机失能”）；两台出厂地址相同的电机如何初始分址（如 1/2）需对照固件确认，本上位机只能向已知地址的电机发命令。
- **读取参数**命令 `0x0C` 使用广播地址 `0xFF`（`7A FF 0C cs 7B`），要求总线上设备回传自身状态。
- 因此，控制某一台电机前，只需把「地址」输入框填成对应地址（1 或 2），再发送相应命令即可；Python 脚本中对应 `BLDCController(address=1|2)`。

### 5.2 `02-host-script\` —— Python 上位机脚本（4 个文件）

| 文件 | 说明 |

| `requirements.txt` | 依赖清单（仅 `pyserial`） |

核心命令方法：`read_params`（读参数）、`set_speed`（速度）、`set_position`（位置）、`set_angle`（角度）、`set_accel`（加速度）、`set_current`（电流）、`angle_zero`（角度置零）、`enable`/`disable`（使能/失能）、`save_params`（保存）、`factory_reset`（恢复出厂）、`set_mode`（模式）。

**特性**：健壮的帧解析（处理粘包/半包/校验失败）、大端序编码、中文注释、语法检查通过。

## 6. 使用方法（Python 脚本）

```bash
cd 02-host-script
pip install -r requirements.txt      # 安装 pyserial
python cli.py                        # 启动命令行界面
```

典型流程：

1. 列出并选择串口 → 连接（默认 921600 波特率）
2. `read_params` 读取当前全部参数
3. `set_speed 300` 设置速度、`set_position 1 1000` 设置位置等
4. `enable` 使能电机 → 观察运行 → `disable` 失能
5. `save_params` 保存到驱动板

> 详细用法见 `02-host-script\README.md`。

## 7. 已知限制与不确定性

逆向产物中以下内容为**推断**，实际以驱动板固件为准：

1. **命令含义**：`0x05/0x06/0x08/0x0A/0x0B`（失能/置零/使能/保存/恢复出厂）的映射已通过 UI 按钮标签与槽函数命令码交叉确认；`0x07`、`0x0F~0x12`（PID）等仍为推断，未在二进制中直接确证。
2. **响应字段单位**：÷10、÷100 的换算系数来自伪代码中的浮点运算常量，建议实测校准。
3. **波特率列表**：程序内有一项 `43000`，疑为 `43200` 的笔误。

如需进一步确证，可：对照驱动板固件源码、用逻辑分析仪抓取串口波形、或在 `03-disasm` 基础上继续深挖。
