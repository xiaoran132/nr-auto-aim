# 串口协议笔记

MiniBalance BLDC 电机上位机与下位机的串口通信协议。

## 1. 帧格式（通用）

所有帧都遵循同一包裹格式：

```
┌─────┬─────┬──────────────┬──────┬─────┐
│ 7A  │ CMD │   DATA(大端)  │ XOR  │ 7B  │
└─────┴─────┴──────────────┴──────┴─────┘
 帧头  命令   数据（变长）    校验  帧尾
```

- 帧头 `0x7A`、帧尾 `0x7B`
- `CMD` 为 1 字节命令码（数据帧的 `CMD` 也常占用数据区第 1 字节）
- 多字节数值一律 **大端（big-endian）**
- 校验和 = **XOR（异或）**，范围：从 `0x7A`（含）到最后一个数据字节（含）

### 校验和算法（反汇编 0x4017C0 确认）

```
401814:  movzbl -0x1(%ebx),%eax   ; 取当前字节
401818:  xor    %al,-0x39(%ebp)    ; 异或累加进累加器
40181b:  cmp    %ebx,-0x44(%ebp)   ; 是否到帧尾
```

逐字节 `xor` 累加，累加器初始为 0。校验字节本身不参与异或。

## 2. 应答帧（下位机 → 上位机）

固定 20 字节（`datareceived` 中 `cmp $0x14,%edi` 校验）：

```
7A | 地址 | F1_H F1_L | F2_H F2_L | F3_H F3_L | F4_H F4_L | F5_H F5_L | F6_H F6_L | F7 F8 F9 F10 | XOR | 7B
```

| 偏移 | 内容 |
|------|------|
| 0 | 0x7A 帧头 |
| 1 | 地址回显（设备回报自身地址，上位机回写「地址」输入框） |
| 2~13 | 6 × 16 位大端（母线电压/速度/机械角度/转过角度/位置/电流） |
| 14~17 | 4 × 8 位（PID×4） |
| 18 | XOR 校验 |
| 19 | 0x7B 帧尾 |

详细字段→控件映射见 `datareceived_analysis.md`。

## 3. 命令表（上位机 → 下位机）

命令帧结构：`7A | 地址 | CMD | [参数(大端)] | XOR | 7B`

- 第 2 字节（`地址`）= 目标设备地址：双电机云台 `1`=下电机、`2`=上电机；
  读取参数命令用 `0xFF` 广播。所有命令帧都携带该地址字节。
- 第 3 字节（`CMD`）= 命令码。

| 命令 | CMD | 参数 | 说明 |
|------|-----|------|------|
| 读取参数 | 0x0C | 无 | `7A FF 0C cs 7B`（FF=广播），下位机返回 20 字节参数帧 |
| 加速度 | 0x01 | 16 位 | `7A addr 01 hi lo cs 7B` |
| 位置（多圈） | 0x02 | 32 位大端 | 位置控制目标（圈数含在 32 位内） |
| 角度 | 0x03 | 16 位 | |
| 速度 | 0x04 | 16 位 | |
| 电机失能 | 0x05 | 无 | `7A addr 05 cs 7B` |
| 电机使能 | 0x06 | 无 | `7A addr 06 cs 7B` |
| — | 0x07 | 16 位 | |
| 保存参数 | 0x08 | 无 | 参数写入 EEPROM/Flash |
| 角度置零 | 0x0A | 无 | `7A addr 0A cs 7B`（当前机械角度设为 0 点） |
| 恢复出厂 | 0x0B | 无 | `7A addr 0B cs 7B` |
| 电流 | 0x0D | 8 位 | 6 字节帧 |
| — | 0x0F / 0x10 / 0x11 / 0x12 | 8 位 | 7 字节帧（PID） |
| 模式 | 0x00 | 8 位 | `7A addr 00 00 mode cs 7B` |

## 6. 连接流程（`0x4021F0` 按钮处理）

1. 读按钮当前文本，若为“连接”则进入连接流程，否则（“断开”）关闭串口
2. `QSerialPort::setPortName`（`0x423598`）— 从串口下拉框取端口名
3. `QString::toInt`（`0x423560`）解析波特率下拉框文本 → `QSerialPort::setBaudRate`（`0x423590`）
4. `QSerialPort::open`（虚表 `+0x38`）打开串口
5. 失败则 `QMessageBox::warning`（`0x4235D8`）弹出“串口打开失败”
